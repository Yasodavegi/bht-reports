Setup
Getting Started
The app is a single HTML file. Open it in Chrome or Edge and it's ready to use.
Download the HTML file
Save BHT_Daily_Report_App.html to a folder you'll always keep it in (e.g. C:\BHTWork\). The file location matters because browser data is tied to it.
Open in Chrome or Edge
Double-click the file to open it in your browser. No internet connection required after the first load.
Configure Settings (first time)
Go to the ⚙ Settings tab and set your client name, staff name, upload your signature, and configure default session times and goals. Click Save Settings.
Select a date and start
Pick today's date from the date bar at the top and click Load / New to begin a new report.
⚠️
Important: Data is stored in the browser's localStorage tied to the exact file path. If you move or rename the file, previous data won't be visible. Always use the same file in the same location. Use Export to Local regularly to keep a backup Excel file.

Data
Export to Local Excel
Export all browser records to a BHT_Reports.xlsx file. Supports smart merging — upload an existing file and only new records are added.
Go to All Reports tab
Click the "📤 Export to Local" button in the top right.
Choose merge or fresh export
Upload existing BHT_Reports.xlsx → merges new records without overwriting old ones.
Ignore & Export Fresh → exports all current browser data as a new file.
File downloads automatically
BHT_Reports.xlsx downloads to your Downloads folder. Move it to your preferred location (e.g. C:\BHTWork\).
✅
The Excel file contains one row per incident with all profile fields (Client Name, Date, Goals, Staff, etc.) repeated on every row for easy filtering and searching in Excel.
Data
Import from Local Excel
Restore all your data back into the browser from a previously exported Excel file. Use this if you accidentally cleared browser cache or switched to a new computer.
Click "📥 Import from Local"
In the All Reports tab, click the blue Import button.
Upload your BHT_Reports.xlsx
A preview appears showing how many dates and incidents were found in the file.
Click "Restore to Browser"
All dates are restored to localStorage. You can then select any date from the date picker and see the full report.
⚠️
Importing will update any matching dates already in the browser with data from the Excel file. Dates not in the Excel file are left untouched.

Tips & FAQ
Common questions and best practices.
💡
Q: I cleared browser cache and lost my data. What do I do?
Open the Import from Local feature in All Reports tab and upload your BHT_Reports.xlsx backup to restore everything.
💡
Q: I moved the HTML file to a new folder and now my data is gone.
Browser data is tied to the exact file path. Move the file back to its original location, or import data from your Excel backup.
💡
Q: I want to use this for a different client or staff.
Go to Settings → update Client Name, Staff Name, upload new signature, adjust goals, click Save Settings. The app is now configured for the new staff/client.
💡
Q: The date/time and file path still show on my printed PDF.
In Chrome print dialog → More settings → uncheck "Headers and footers". Chrome remembers this setting for future prints.
💡
Q: Can I add more than 3 goals?
Yes! Go to Settings → Goals section → click "+ Add Goal" to add as many as needed. Delete any with the × button.
✅
Best Practice: Export to Local at the end of each week to keep a running Excel backup. Keep the HTML file and Excel file in the same folder (e.g. C:\BHTWork\) for easy access.
